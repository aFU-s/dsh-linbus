# 边狱巴士每日（Limbus Company）

这个 skill 是 dsh-game-daily 里 `game-daily-*` 技能的边狱巴士版本：
**插件提供手和眼睛（limbus_* 工具），这里提供“怎么打”的流程与安全边界。**

> 前置：DSH 已装 `dsh-limbus-control`，游戏窗口已打开、已登录。
> 坐标按 1920×1080、16:9 客户区标定；换分辨率后先用截图复核。

## 0. 铁律

1. **不碰付费内容**：不点「提取」（抽卡）、不在「自动贩卖机」里购买任何东西、不消耗狂气换体力。
2. **只在确认过的界面点**：每步先 `limbus_screenshot` + `read_image`，画面不对就停，绝不盲点。
3. **认不出就停**：未知弹窗、网络错误、加载超过 60 秒 → 写报告 `status=partial`，把截图路径带上。
4. **默认一次最多 3 场经验本**；用户明确要求再加。
5. **进入战斗前确认模块 ≥ 3**（底部绿色圆环数字）；不够就停。
6. **不在主账号上无人值守**：官方 2026-04-06 公告监控宏/脚本，风险自负。

## 1. 开跑前

1. `limbus_status` 确认窗口存在、客户区 1920×1080、未最小化。
2. 生成 runId：`<YYYYMMDD-HHmmss>`。
3. 如果已经在战斗中（画面有 TURN / START），跳到第 4 节继续，不要重开。
4. 如果不在主界面，点左上返回箭头 `(0.07, 0.06)`，每点一次截图确认，最多 3 次。

## 3. 经验采光（核心日常）

1. 点底部「驾驶席」`(0.764, 0.92)`，截图确认看到红色地图。
2. 点「采光」`(0.340, 0.260)`，截图确认看到「经验 / 纺锤」两个页签和三张关卡卡。
3. 选最右关卡（STAGE 10，推荐 LV63）：点「进入」`(0.870, 0.660)`。
   - 点不动就原坐标再点一次；**不要点下面那行「跳过战斗」`(0.870, 0.710)`**——它会消耗 6 模块。
   - 进入成功会看到选人界面。
4. 选人界面：点顶部一排 6 张卡，坐标
   `(0.229, 0.328, 0.427, 0.526, 0.625, 0.722)`，y=`0.320`。
5. 截图确认「参战人数 6/12」且「开始战斗」变亮；点 `(0.880, 0.830)`。
6. 进入战斗后：

   ```
   循环（最多 12 回合）：
     limbus_screenshot + read_image
     如果是「TURN n」规划界面：
       limbus_key("p")       # 自动选技能
       limbus_wait(700)
       limbus_key("enter")   # 开始本回合（实测比点 START 稳）
       limbus_wait(12000)    # 等动画
     如果是结算/胜利界面：跳出循环
     如果画面 2 个回合没有变化：停止，报 partial
   ```

7. 结算界面：截图确认奖励，点「确认/继续」（视觉找按钮，不写死坐标），直到回到采光页面。
8. 需要重复时，回到第 3 步；每场消耗 3 模块，开跑前复核。

## 4. 战斗中接手（如果已经在战斗里）

1. 截图判断阶段：
   - `TURN n` + 底部技能条 → 规划阶段：`p` → `enter`。
   - 动画/伤害数字 → `limbus_wait(10000)` 再看。
   - 胜利/结算 → 第 3.7 步。
2. 不要点「暂停」里的「放弃战斗」，除非用户明确要求。

## 5. 领取奖励（探索步骤，v1 保守处理）

1. 点「玻璃窗」`(0.638, 0.92)`，截图。
2. 如果看到邮件列表：点「全部领取」（视觉定位），截图确认；领完返回。
3. 如果界面不认识：**停**，把截图路径写进报告，标记 `partial`，不要乱点。
4. 「镜像迷宫」「折射轨道」v1 不自动打；用户点名时再单独探索。

## 6. 报告

在本工作区写 `dsh-limbus-control/runs/<runId>/report.json`：

```json
{
  "schemaVersion": 1,
  "runId": "20261028-060000",
  "game": "limbus",
  "mode": "real",
  "status": "success | partial | failed | timeout",
  "startedAt": "2026-10-28T06:00:00+08:00",
  "endedAt": "2026-10-28T06:12:00+08:00",
  "steps": [
    { "name": "open-caiguang", "ok": true, "at": "...", "screenshot": "C:\\...\\shot.png" }
  ],
  "runs": 1,
  "notes": "一句话说明结果/异常"
}
```

`status` 规则：

- `success`：计划场次全部打完并领奖；
- `partial`：打了一部分 / 领奖界面不认识；
- `failed`：没进战斗或连续 2 回合无进展；
- `timeout`：超过 30 分钟。

最后用 3–5 行向用户汇报：打了几场、消耗多少模块、领了什么、卡在哪（带截图路径）。

## 7. 调试

- 每步截图保存到 `C:\Users\Administrator\AppData\Local\Temp\dsh-limbus-control\shots`；
- 点不动时先 `limbus_focus` 再点；
- 坐标偏移：用截图里的像素位置 ÷ 截图宽高，重新算相对坐标。
